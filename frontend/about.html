The frontend version above is baked into this HTML/JS bundle at packaging time (see the VYNE_VERSION constant near the top of vyne-client.js). The backend version is fetched live from GET /api/version. If a redeploy of one side didn't actually go out — a stale local checkout, the wrong Firebase project selected, a Cloud Run deploy that silently no-op'd — the two will disagree, and that disagreement is exactly what the banner above is watching for.
